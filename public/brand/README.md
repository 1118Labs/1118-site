# 1118 identity — system overhaul

The current mark uses vector paths, not text or an embedded raster image. Its transparent background works on every surface.

- `1118-mark-dark.svg`: navy wordmark for white and pale backgrounds.
- `1118-mark-light.svg`: white wordmark for navy or black backgrounds.
- `1118-avatar.svg`: transparent square composition.
- `1118-avatar-dark-256.png` / `1118-avatar-light-256.png`: transparent avatar exports.
- `1118-og.svg`: source for the intentional white 1200×630 social composition in `/og.png`; embeds the project's licensed Manrope font.

The header/footer inline paths match these SVG assets. Browser and Apple icons use the same geometry. The historical blue PNG is retained as an unused source asset.
