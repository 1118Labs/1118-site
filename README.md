# 1118

The public homepage for 1118, an AI-first product studio.

This focused one-page site introduces the studio and its flagship product,
[Etchr.ai](https://etchr.ai).

## Local development

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).

## Validation

```bash
npm run lint
npm run typecheck
npm run build
```
